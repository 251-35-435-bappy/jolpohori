# Jolprohori UI Project

এই প্রজেক্টটি একটি মডুলার এবং দক্ষ ব্যবহারকারী ইন্টারফেস (User Interface) যা HTML5, CSS3 এবং ভ্যানিলা জাভাস্ক্রিপ্ট ব্যবহার করে তৈরি করা হয়েছে।

## বৈশিষ্ট্য (Features)
- **বাংলা ভাষা** - সম্পূর্ণ ইন্টারফেস বাংলাদেশি ব্যবহারকারীদের জন্য বাংলা ভাষায়
- **মডুলার ডিজাইন** - প্রতিটি মডিউল পৃথক পৃথক ফাইলে রাখা হয়েছে
- **দক্ষness** - হালকা ওজন, দ্রুত লোডিং, কোনো ভারী ফ্রেমওয়ার্ক নেই
- **রেসপনসিভ** - মোবাইল, ট্যাবলেট এবং ডেস্কটপের জন্য উপযোগী
- **স্থানীয়করণ** - নির্দিষ্ট এলাকার ব্যবহারকারীদের জন্য উপযোগী

## ফাইল কাঠামো
- `index.html` - প্রধান এন্ট্রি পয়েন্ট
- `css/style.css` - প্রধান স্টাইলশীট
- `css/modules.css` - মডিউল-নির্দিষ্ট স্টাইল
- `js/app.js` - প্রধান অ্যাপলিকেশন কন্ট্রোলার
- `js/modules/` - পৃথক মডিউল স্ক্রিপ্ট
- `js/i18n.js` - বাংলা ভাষার অনুবাদ
- `assets/` - ছবি, আইকন এবং ফন্ট
